# Contributing

## APIs listed on PayAPI Market

These appear automatically once a test payment settles on-chain. To get an API listed, register it on [payapi.market](https://payapi.market).

The tables in `README.md` are generated by `scripts/generate-readme.mjs`. Do not edit them by hand; changes are overwritten on the next daily regeneration.

## Other x402 APIs

APIs that are not on PayAPI Market can be added to the "Other x402 APIs" section.

- One API per pull request.
- Edit `data/external.md` only. Do not edit `README.md`.
- Keep rows in alphabetical order by API name.
- Descriptions must be under 100 characters and use a neutral tone, with no promotional language.
- The listed route must return a valid x402 `402 Payment Required` challenge.

Dead links and APIs that stop returning a valid 402 challenge are removed.

## Development

```sh
npm test                          # unit tests
node scripts/generate-readme.mjs  # regenerate README.md from the live catalogue
node scripts/generate-readme.mjs --input test/fixtures/listings.json  # offline run
node scripts/generate-readme.mjs --check                              # exit 1 if README.md is out of date
```
